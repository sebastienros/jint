# W3C XML namespace test fixtures

`W3cNamespaceFixtureTests.cs` includes fixtures 007, 009, 012, and 021 from
`xmlconf/eduni/namespaces/1.0/` in the [W3C XML Conformance Test Suite,
10 December 2003](https://www.w3.org/XML/Test/xmlconf-20031210.html).
The archive is available at `https://www.w3.org/XML/Test/xmlts20031210.tar`.
