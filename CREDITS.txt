This file contains the list of open-source tools Jint is using directly or indirectly

Esprima
-----
Jint contains a C# port of the Esprima Javascript parser.

Website:      http://esprima.org/
Copyright:    Copyright (c) Ariya Hidayat
License:      BSD - https://github.com/ariya/esprima/blob/master/LICENSE.BSD

Google Inc
-----
Jint uses the FastDtoa algorithm implemented for Google V8

Copyright:    Copyright 2010 the V8 project authors. All rights reserved.

Mozilla
-----
Jint number serialization is based on the Java port of the FastDtoa algorithm from Mozilla

Website:      http://mozilla.org/
Copyright:    Copyright (c) Mozilla
License:      MPL 2.0 - http://mozilla.org/MPL/2.0/

MimeKit
-----
Jint date parsing utilizes code extracted from the excellent MimeKit library.

Website:      https://github.com/jstedfast/MimeKit
Copyright:    Copyright (C) 2012-2022 .NET Foundation and Contributors
License:      MIT - https://github.com/jstedfast/MimeKit/blob/master/LICENSE

WHATWG
-----
Jint's TextDecoder decodes the legacy encodings through the index and label tables of the Encoding
Standard, generated from the standard's own data files (vendored under tools/whatwg-encoding/).

Website:      https://encoding.spec.whatwg.org/
Copyright:    Copyright (c) WHATWG (Apple, Google, Mozilla, Microsoft)
License:      CC BY 4.0, and BSD 3-Clause for the portions incorporated into source code -
              https://github.com/whatwg/encoding/blob/main/LICENSE

Unicode CLDR
-----
Jint's Intl implementation embeds data derived from the Unicode Common Locale Data Repository (CLDR):
likely subtags, week data, locale tag mappings, calendar preferences, metazones, and the compact, list,
relative-time and unit patterns under Jint/Native/Intl/Data/.

Website:      https://cldr.unicode.org/
Copyright:    Copyright © 1991-2026 Unicode, Inc.
