# Jint Documentation

Jint embeds JavaScript in a .NET process. Install the `Jint` package, create an `Engine`, and add only the
capabilities your application intends to expose. The rest of this documentation starts from that core runtime.

## Recommended path

1. [Install Jint and run a script](getting-started.md).
2. Learn how to [create and configure an engine](./creating-an-engine.md).
3. Configure [constraints and untrusted-code protection](./untrusted-code.md) before accepting
   scripts you do not control.
4. Add an [additional package](choosing-a-package.md) only when you need debugging or browser functionality.

Upgrading an existing application? Read [Migrating to Jint 5](migrating-to-v5.md) first.
