# Guide

Jint embeds JavaScript in a .NET process. Start with the core `Jint` package, create an `Engine`, and add only
the capabilities your application intends to expose.

## Recommended path

1. [Install Jint and run a script](getting-started.md).
2. Learn when to use each [public package](choosing-a-package.md).
3. Review the [supported platforms](supported-platforms.md).
4. Configure [constraints and untrusted-code protection](../packages/jint/untrusted-code.md) before accepting
   scripts you do not control.

Upgrading an existing application? Read [Migrating to Jint 5](migrating-to-v5.md) first.
